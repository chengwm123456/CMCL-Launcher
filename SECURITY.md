##### Supported Versions

No versions has been published.

Normally, the latest version is supported.

##### Reporting a Vulnerability

Go to the "Issues" page -> "New issue", choose "Security Vulnerability", and follow the format in the template to
complete your report.

Normally, the update will be published after the vulnerability is fixed.

If the vulnerability is in our code, we'll find a suitable way to fix.

If the vulnerability is caused by dependency libraries, the update will be published when the new update of the library
is published, or we can use some code to fix it.
