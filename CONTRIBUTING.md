<h5>Finding improvements</h5>

* Sometimes the author will leave somewhere like this:
  ```python
  # TODO: [Something will do]
  ```
  If you see this, then......
  > "Hey, chengwm. Can I help you?"
  >
  > "Let me create a new Pull request!"
  >
  > "..."
* Check the issues page, find an issue that you know how to solve, **even a little**
* Launcher is an open-source project, you can look the source.
* Or just use the launcher.
    * I mean, if the launcher crashed or stuck, and there were some text in `error.log`......
    * Keep the log then report.

<h5>Coding</h5>
First, you should be willing to contribute to the project. (I won't force anyone to do this)

If you're willing to contribute, you can contribute with us.

But,

- Please don't vandalise this project unless you think that git and GitHub aren't exist.
  (If you think that GitHub isn't exist, probably ...... this is the last time you see this guideline)
- Please leave a message when you're committing.
